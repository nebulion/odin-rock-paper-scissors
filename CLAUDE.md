## generate_gpx.py

### Purpose

Generates two GPX files with dense, road-following track points using OSRM (OpenStreetMap routing). Each GPX contains multiple `<rte>` (route) and `<trk>` (track) elements — one per loop variation.

### Running It

```bash
pip install requests
python3 generate_gpx.py
```

Outputs `ha-giang-loop.gpx` and `cao-bang-loop.gpx` in the current directory. Takes ~1–2 minutes (OSRM API calls, rate-limited politely at 0.3s per segment).

### What It Does

1. Defines named waypoints with verified coordinates for both loops
2. For each route variation, calls OSRM segment-by-segment: `GET https://router.project-osrm.org/route/v1/driving/{lon,lat};{lon,lat}?overview=full&geometries=geojson`
3. Extracts `routes[0].geometry.coordinates` (GeoJSON `[lon, lat]` pairs)
4. Writes `<trkpt lat= lon=>` elements — actual road geometry, not straight lines
5. Falls back to 50-point linear interpolation per segment if OSRM is unreachable

### Coordinate Sources

All waypoint coordinates were verified against multiple sources:

- **Wikipedia** — Lung Cu Flag Tower (DMS `23°21′49″N 105°18′58″E`), Ma Pi Leng Pass, Ban Gioc Waterfall
- **vietnamtourism.gov.vn** — official Vietnam tourism authority
- **looptrails.com** — Nguom Ngao Cave (`22.8536°N, 106.7244°E`)
- **latlong.net / nominatim.openstreetmap.org** — Cao Bang City (`22.6657°N, 106.2522°E`)
- Cross-referenced across: vietnam-coracle.com, motorbiketourexpert.com, hagianggo.com

## Route Coverage

### Ha Giang Loop (`ha-giang-loop.gpx`)

Five variations, all starting/ending at Ha Giang City:

| Variation | Distance | Days |
|-----------|----------|------|
| Classic Clockwise | ~350 km | 3–4 |
| Counter-Clockwise | ~350 km | 3–4 |
| Extended with Lung Cu Flag Tower | ~400 km | 4–5 |
| Short 2-Day Express | ~280 km | 2 |
| Full Grand Tour (all highlights) | ~430 km | 5–7 |

Key road: **National Highway 4C (QL4C)** through the Dong Van Karst Plateau UNESCO Geopark.

### Cao Bang Loop (`cao-bang-loop.gpx`)

Five variations, all starting/ending at Cao Bang City:

| Variation | Distance | Days |
|-----------|----------|------|
| Classic Ban Gioc | ~220 km | 2–3 |
| Extended with Pac Bo | ~320 km | 3–4 |
| Southern Phia Oac Variation | ~380 km | 3–4 |
| Full Grand Loop (all highlights) | ~480 km | 5–7 |
| Ha Giang → Cao Bang Connector (Meo Vac → Bao Lac) | ~180 km | 1 |

Key roads: **QL3, QL34, Provincial Road 205** through the Non Nuoc Cao Bang UNESCO Geopark.

## Development Conventions

### When modifying waypoints

- Always cite the source in a comment next to the coordinate
- Prefer DMS-derived decimal over rounded estimates when Wikipedia provides DMS
- Cross-check against OpenStreetMap (nominatim.openstreetmap.org) before committing

### When modifying routes

- Keep waypoint names consistent between `*_WAYPOINTS` dict and `*_ROUTES` dict
- The connector route (`Meo Vac Town`) borrows from `HA_GIANG_WAYPOINTS` — this is intentional; the line `CAO_BANG_WAYPOINTS["Meo Vac Town"] = HA_GIANG_WAYPOINTS["Meo Vac Town"]` must stay

### GPX format conventions

- Both `<rte>` (simple point-to-point, for viewers) and `<trk>` (dense road geometry) are included per route
- Track points use 6 decimal places of precision
- File encoding: UTF-8

### Network access note

This Claude Code environment's sandbox **blocks all outbound HTTP** except GitHub API and package registries (npm, pip, etc.). OSRM, Overpass API, Nominatim, WebFetch to travel sites — all return 403. The script must be run locally. WebSearch (text summaries only) and GitHub MCP tools do work.

## Original Project (Historical)

The repo started as an Odin Project JavaScript exercise. Two commits remain in history:

- `806f340` — `index.html`: prompt-based Rock Paper Scissors game (5-round, best of 5)
